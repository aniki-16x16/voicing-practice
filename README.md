# 和弦之间

练习双手和弦连接的键盘工具。左手承担低音，可增加五度与八度支撑；按分段自然大调的级数编辑根音和低音，五线谱与键盘同步高亮。

## 使用

1. 每小节四拍。点击任意一拍，用 1–7 级与互斥的 ♭／♯ 按钮设置根音、低音；基础和弦、附加音与分段参照的菜单铺满抽屉内容宽度，用 tag 排列选项。附加音支持多选，选中后点击右侧 × 可全部清空。修改即保存，点击「完成编辑」关闭抽屉。
2. 在任意和弦处设置分段参照大调。切换调性时保留本段根音与低音的级数及其升降，实际和弦随之移调，直到下一个明确的调性标记。选择「沿用前段」会按前段调性移调；和弦性质、附加音和最高音设置保留。
3. 顶栏设置图标打开独立的全局设置抽屉，可调整六种 Voicing 预设、右手音区、单手最大跨度、单手音数上限（4／5，默认 4）、连接目标、速度与循环。跨度分别约束每只手，提供八度、九度和十度；左手低音计入音数与跨度。和弦编辑抽屉标题栏显示拍位，左右按钮只切换到已设置和弦的位置。
4. 底栏提供首尾跳转、播放／暂停与循环开关，空格键切换播放／暂停（编辑抽屉与输入框内不触发）。暂停回到当前小节开头；点击谱面仅移动游标，试听请用键盘上方的喇叭按钮。底栏和全局设置中的 BPM 都支持直接输入后按 Enter 或离开输入框确认、点按加减和上下方向键微调，Shift 每次调整 5 BPM；播放中调速立即生效。
5. 和弦轨道与五线谱支持左右拖动，播放优先让当前小节居中；边缘渐隐和箭头提示更多内容。轨道末尾的加号添加小节。
6. 长按和弦约半秒，看到删除提示后向任意方向拖动约 48px 即可删除；普通拖动不会删除。也可聚焦和弦后按 Delete。删除后延续前一个和弦，首个和弦之前的空拍为休止；所有和弦删除后仍可点空拍重新设置。
   编辑抽屉底部左侧可删除当前整个小节：没有设置和弦时，实心按钮点击即删；有和弦时，空心按钮长按 1.2 秒，背景从左向右填满后删除，提前松开则快速退回。删除后切换到相邻小节；最后一个小节也可删除，再用轨道加号添加。
7. 和弦列表在卡片底部留白处显示实际和弦名称，用淡紫背景标记设定最高音的和弦。点击任意和弦，在「最高音（Top note）」中选择和弦的几音，例如「3 音」「7 音」「9 音」；选项只显示数字，不显示升降号或具体音名。每个和弦可独立固定最高音，允许相邻和弦连续设置，未固定的和弦自动优化。轨道不显示 Top note 文字；无解的和弦改用红色背景，具体原因只显示在该和弦的编辑抽屉中。连接目标是偏好，优先保留固定最高音，不提示连接取舍。选择「自动优化」仅解除当前和弦，也可在抽屉中「清除全部固定」。双手模式控制右手最高音，左手低音不变；单练左手时控制左手 Shell 的最高音，自动调整排列并保留明确指定的斜杠低音。
8. 在「最高音（Top note）」中选择「每轮自动换最高音」会同时开启循环播放，在整段结束后分别轮换所有开启此选项的和弦最高音，单练左手也生效。同一轮内不会改变排列；任意下一最高音无解时暂停，对应卡片变红，原因放在其编辑抽屉中，不跳过。关闭循环播放则只弹一遍。选择「自动优化」或删除和弦只解除该和弦的设置；选择固定最高音只停止该和弦的轮换。

进行自动保存在当前浏览器本地，无需账号、网络音源或 AI 服务。旧版本每个和弦迁移为一个小节，不删除旧版存储。

各和弦的最高音与自动轮换开关也在本地保存，兼容迁移旧版的单个最高音设置。更改和弦性质、预设或练习模式后，如果指定的最高音不再适用，工具会要求重新选择。旧版最低音转位设置保留在旧存储中，不会被解释成最高音设置。

## 标记与规则

- 大和弦 M，小和弦 m，属和弦直接加数字，增 aug，减 dim，减七 dim7，半减七 m7b5。支持挂留、加九、小大七及部分变化属和弦。
- 升降号前置于级数；斜杠后是低音级数。保留等音拼写：C 参照下 F# 是 #4，Gb 是 b5。
- 双手模式左手最低音固定在 C2–B2；指定低音优先于根音。左手丰满和双手丰满预设在低音上方增加支撑：低八度仅开放纯五度，其他音放在上方八度，并避免密集相邻音。空间不足时可以减少音数。单练左手使用中低音区 Shell，自动枚举跨度内各骨架音的八度位置，包括 1–3–7 与 1–7–3 等排列，再优化整段连接。例如十度跨度下 Dm7 的 D3–F3–C4 可连接 G7 的 G2–F3–B3。自动模式保留根音或指定低音；指定最高音且需要转位时允许调整最低音，明确指定的斜杠低音仍保留。
- 基本排列：右手完整保留三和弦或七和弦骨架，有余量再加入所选附加音。Shell 骨架：保留根音、三音／挂留音、七音与变化五音；没有七音时保留三音骨架。
- 右手无根排列：左手低音，右手省根音，优先三音、七音及所选色彩音。右手丰满排列：允许省普通五音，或在不同八度重复根音、普通五音。
- 左手丰满排列：低音加五度／八度等支撑，右手精简并补足特征音。双手丰满排列：左手保持低音职责，右手增加和声与色彩，双手共同分配构成音。
- 不添加未选择的扩展音；挂留替代三音，变化五音不会随意省略。键盘上方显示每手音数及本次省略的构成音。上限是限制，不要求每手弹满。
- 在音数、音区、每手跨度与双手不交叉的约束内枚举候选。丰满预设保留各右手起音音区的优选候选，再以动态规划寻找候选中的整段最低代价路径，同分顺序固定。
- 代价考虑双手声部移动、大跳、声部增减、色彩音保留与低音清晰度。最高声部上行/下行是偏好，不是每步硬性要求。
- 循环播放重复同一路径，暂不优化末尾到开头的连接。
- 谱面依据小节内延续拍数显示四分、二分、附点二分或全音符；跨小节延续用延续标记提示。高低音谱表按分段大调显示调号，支持小节内转调及旧调号的还原。临时升降号按各谱表、八度在小节内生效，小节线或转调后重置。试听为合成音色。
- 第一版不含 MIDI 输入评分、指法推荐或采样钢琴音色。

## 开发

### iPad 主屏幕应用

部署更新后，在 Safari 中刷新页面，通过「分享 → 添加到主屏幕」安装，再从主屏幕图标启动，即可隐藏浏览器地址栏、标签栏与工具栏。已有的旧快捷方式需要移除后重新添加；iPadOS 26 及以上添加时保持「作为 Web App 打开」（Open as Web App）开启。系统状态栏和底部手势条由 iPadOS 控制，仍可能显示。

应用清单请求全屏显示，并提供兼容旧版 iPadOS 的独立应用声明。启动地址、作用域和图标均跟随部署目录，兼容本地开发路径与 GitHub Pages 的 `/voicing-practice/` 路径。主页面与抽屉会为系统安全区域保留空间；这项配置不提供离线缓存。

### 本地开发

使用 Node.js 24，运行 npm install、npm run dev。验证命令：npm test、npm run build、npm run lint。

和声规则位于 src/music.ts，拍位与分段移调规则位于 src/practice.ts，调号及临时升降号规则位于 src/notation.ts。谱面、自定义下拉框与键盘分别位于 src/Staff.tsx、src/Select.tsx 和 src/Keyboard.tsx。测试覆盖和弦生成、分段移调、最高音约束与左手轮换、调号切换、临时升降号、二度音簇错位和拍位延续。
